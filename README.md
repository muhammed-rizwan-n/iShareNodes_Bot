# iShareNodes

**iShareNodes** is a shared masternode hosting platform that operates via **Discord**, allowing users to participate in masternodes without requiring full ownership of a node. The platform aims to lower the entry barrier for investors while maximizing security, transparency, and profitability. iShareNodes provides a seamless and automated process for pooling cryptocurrency funds, managing collateral, and distributing rewards among participants.

## 🤖 Bot Architecture

The project is powered by **three dedicated Discord bots**, each responsible for a specific set of operations:

- **Client Bot**: Handles all client-side operations and user interactions.
- **Master Bot**: Manages the core database, tracks user requests, and coordinates internal logic.
- **Wallet Bot**: Responsible for wallet management and secure handling of cryptocurrency transactions.

👉 Each bot’s operations are documented in separate README files.
